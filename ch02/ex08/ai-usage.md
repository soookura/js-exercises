# AI 利用記録 (ch02/ex08: AST)

## acorn の使い方

- 状況: acorn をどう呼ぶか分からず、コードを文字列にせず渡そうとした。
- 聞いたこと: acorn の使い方。
- 結果: パーサーはソースを文字列として受け取ると分かった。
  クォートなしで `1 + 1` を渡すと JS が先に計算して `2` になってしまう。

## JSON として出力する書き方

- 状況: `console.log(ast)` だと `declarations: [Array]` と省略され、中身が見えなかった。
- 聞いたこと: JSON として出力する書き方。
- 結果: `JSON.stringify(ast, null, 2)` の第 3 引数がインデント幅だと分かった。
  第 2 引数は使わないので null を置く。

## 出力された AST の読み方

- 状況: 出力された JSON が何を意味するのか読めなかった。
- 聞いたこと: AST の読み方。各 type は何を表すのか。
- 結果: `VariableDeclaration` は変数宣言文、`Literal` は書かれた値など、
  type が「これは何か」を表すと分かった。`start` / `end` は文字位置。

## ツリー構造への図式化

- 状況: JSON からどう木を描けばよいか分からなかった。
- 聞いたこと: ツリー構造の作り方。
- 結果: type を節、キー名を枝のラベルにすれば機械的に描けると分かった。
  `start` / `end` は構造ではないので木には描かない。
