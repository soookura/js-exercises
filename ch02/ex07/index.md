# 出力結果

0 1 0
1 1 0

# 理由

前置演算子（const x = ++y）では、yを1増やしそれをxに代入
後置演算子（const x = y++）では、xにyを代入し、yを1増やす

参考書本文(p23)より
「これらの演算子を、後置演算子として使いたいのであれば、式と同じ行に記述してください。」とある。

一つ目のコードは、++をaと同じ行に書いていないため、

```javascript
const c = a;
++b; // 前置演算子
```

と解釈され、a=0, b=1, c=0と解釈される。

二つ目のコードは、同じ行に++が書かれているため

```javascript
const e = a++; // 後置演算子
b;
```

と解釈され, bは一つ目のコードで1に加算されているため、a=1, b=1, e=0と解釈される。
