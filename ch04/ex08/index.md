# 解答

undefinedのMDN引用：「古いブラウザーを除くすべてのブラウザーでは、 undefined は、設定不可、書込不可のプロパティとなります。 (そうでない場合でも、上書きは避けてください。)」より、古いブラウザではグローバルのundefinedを書き換えることができたため、確実にundefinedを使用するために、void 0が使用されていた。
