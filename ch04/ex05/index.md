# 回答

## コード

```javascript
for (i = 1; i < 101; i++) {
  console.log((i % 3 ? "" : "Fizz") + (i % 5 ? "" : "Buzz") || i);
}
```

## Fizz(例：i=3)

- まず丸括弧内の(i % 3 ? "" : "Fizz") と(i % 5 ? "" : "Buzz") が評価される。（p78引用）
- (i % 3 ? "" : "Fizz")ではi % 3 は 0となり、falseに変換できるため、3番目のオペランドの"Fizz"が返る（p99引用）
- 次いで(i % 5 ? "" : "Buzz") ではi % 5 は 3 でtrueに変換できるため、""が返る。
- p76の表4-1より、+と||では+のほうが優先順位が高いため、まず"Fizz" + "" が実行され、"Fizz"が返る。
- 最後に"Fizz" || iとなり、左辺の式である"Fizz"が、trueに変換されるため、そのまま"Fizz"が返される。（p92引用）

## Buzz(例：i=5)

- (i % 3 ? "" : "Fizz")ではi % 3 は 2となり、trueに変換できるため、""が返る。
- 次いで(i % 5 ? "" : "Buzz") ではi % 5 は 0 でfalseに変換できるため、"Buzz"が返る。
- +が先に実行され"Buzz"が返る。
- "Buzz" || iとなり、"Buzz"が、trueに変換されるため、そのまま"Buzz"が返る。

## FizzBuzz(例：i=15)

- (i % 3 ? "" : "Fizz")ではi % 3 は 0となり、falseに変換できるため、"Fizz"が返る。
- 次いで(i % 5 ? "" : "Buzz") ではi % 5 は 0 でfalseに変換できるため、"Buzz"が返る。
- "Fizz" + "Buzz" が先に実行され"FizzBuzz"が返る。
- "FizzBuzz" || iとなり、"FizzBuzz"が、trueに変換されるため、そのまま"FizzBuzz"が返る。

## 数値(例：i=4)

- (i % 3 ? "" : "Fizz")ではi % 3 は 1となり、trueに変換できるため、""が返る。
- 次いで(i % 5 ? "" : "Buzz") ではi % 5 は 4 でtrueに変換できるため、""が返る。
- "" + "" が先に実行され""が返る。
- "" || iとなり、""がfalseに変換されるため、右辺のiの値が返される。
