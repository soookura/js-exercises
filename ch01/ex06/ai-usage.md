# AI 利用記録 (ch01/ex06: fib)

解答コードは書かせず、ヒントのみを求める形で利用した。

## 1. 実装方針が立たない

- 聞いたこと: fib はどう実装すればよいか。再帰を使うのか。引数は 1 つでよいか。
- 結果: 素直な再帰では fib(75) が終わらないと分かり、ループで書く方針にした。

## 2. 計算結果が合わない

- 状況: ループ内を `a = b; b = a + b;` と書いたら fib(5) が 12 になった。
  一時変数をループの外で宣言したら今度は 4 になった。
- 聞いたこと: どこが間違っているか。
- 結果: `a = b` の時点で古い `a` が失われるのが原因と分かった。
  一時変数をループの中で毎回取り直す形に自分で修正した。

## 3. ESLint の警告

- 状況: `prefer-const` の警告が出た。ループ内の変数なのに const でよいのか疑問だった。
- 聞いたこと: なぜ const にしてよいのか。スコープの仕組み。
- 結果: ブロックは実行のたびに別の変数が作られるため再代入ではないと理解し、const に直した。
